# OSC Genome Analysis for Publication

Collection of R scripts used to evaluate the quality of the OSC genome for the publication:

**The Drosophila OSC Genome: A Resource for Studies of Transposon and piRNA Biology**

Handler et al., 2025

## Overview
This repository contains scripts and tools used to evaluate the quality and features of the OSC genome. Included are analysis regarding its quality, the TE-landscape and piRNA pathway related topics (piRNA cluster coverage of TEs, splicing within flamenco, silencing of flamenco by tethering)
